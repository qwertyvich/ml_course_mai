Лабораторная работа № 2. Классификация¶

Цель: прогноз выживания пассажиров Titanic и сравнение Decision Tree, Random Forest, Gradient Boosting, SVM и KNN с константным baseline.

Целевая переменная — Survived: 1 — выжил, 0 — погиб. Основная метрика — F1 для класса 1, минимальный порог — F1 > 0.70. Дополнительно рассчитаны Accuracy, Precision, Recall и матрицы ошибок.

Источник данных: Titanic Dataset, Yasser H — Kaggle. Основание работы: lab02.pdf, classification.ipynb, metrics.ipynb и preza.pdf из материалов курса.

4. Предобработка¶

Числовые пропуски заполняются медианой train, категориальные — наиболее частым значением train. Pclass, Sex и Embarked кодируются One-Hot. Для SVM и KNN числовые признаки дополнительно стандартизуются: их алгоритмы зависят от геометрии и расстояний. Для деревьев масштабирование не применяется. Все обучаемые преобразования включены в Pipeline и заново обучаются внутри каждого CV-фолда.

In [7]:
def make_preprocessor(scale_numeric=False):
    numeric_steps = [('imputer', SimpleImputer(strategy='median'))]
    if scale_numeric:
        numeric_steps.append(('scaler', StandardScaler()))

    categorical_steps = [
        ('imputer', SimpleImputer(strategy='most_frequent')),
        ('onehot', OneHotEncoder(handle_unknown='ignore', sparse_output=False)),
    ]
    return ColumnTransformer([
        ('num', Pipeline(numeric_steps), numeric_features),
        ('cat', Pipeline(categorical_steps), categorical_features),
    ])


def make_model(classifier, scale_numeric=False):
    return Pipeline([
        ('preprocess', make_preprocessor(scale_numeric)),
        ('classifier', classifier),
    ])

5. Метрики и baseline¶

Положительный класс — Survived=1. Использованы:

$$Accuracy=\frac{TP+TN}{N},\quad Precision=\frac{TP}{TP+FP},\quad Recall=\frac{TP}{TP+FN},$$ $$F_1=\frac{2PR}{P+R}=\frac{2TP}{2TP+FP+FN}.$$

FP — погибший пассажир, ошибочно предсказанный выжившим; FN — выживший, ошибочно предсказанный погибшим. zero_division=0 задаёт нулевую метрику при отсутствии положительных предсказаний.

In [8]:
def classification_metrics(y_true, y_pred):
    return {
        'Accuracy': accuracy_score(y_true, y_pred),
        'Precision': precision_score(y_true, y_pred, pos_label=1, zero_division=0),
        'Recall': recall_score(y_true, y_pred, pos_label=1, zero_division=0),
        'F1': f1_score(y_true, y_pred, pos_label=1, zero_division=0),
    }


scoring = {
    'Accuracy': 'accuracy',
    'Precision': make_scorer(precision_score, pos_label=1, zero_division=0),
    'Recall': make_scorer(recall_score, pos_label=1, zero_division=0),
    'F1': make_scorer(f1_score, pos_label=1, zero_division=0),
}

7. Кросс-валидация и выбор решения¶

Использована StratifiedKFold(n_splits=5, shuffle=True, random_state=42). Варианты сравниваются по среднему F1 класса 1 на общих проверочных фолдах. В таблице также приведены остальные CV-метрики, разброс F1 и средняя обучающая F1.

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=RANDOM_STATE)
cv_rows = []
for name, model in candidates.items():
    scores = cross_validate(
        model, X_train, y_train, cv=cv, scoring=scoring,
        return_train_score=True, n_jobs=1, error_score='raise',
    )
    row = {'Вариант': name}
    for metric in scoring:
        row[f'CV {metric}'] = scores[f'test_{metric}'].mean()
    row['CV std F1'] = scores['test_F1'].std()
    row['Train F1'] = scores['train_F1'].mean()
    cv_rows.append(row)

def group_error_metrics(frame, column):
    rows = []
    for group, part in frame.groupby(column, dropna=False):
        matrix = confusion_matrix(part['y_true'], part['y_pred'], labels=[0, 1])
        rows.append({
            'Группа': group,
            'N': len(part),
            'Выживших': int(part['y_true'].sum()),
            'Доля ошибок': part['wrong'].mean(),
            'F1': f1_score(part['y_true'], part['y_pred'], zero_division=0),
            'FP': int(matrix[0, 1]),
            'FN': int(matrix[1, 0]),
        })
    return pd.DataFrame(rows).set_index('Группа')

12. Заключение¶

Сравнены пять обязательных алгоритмов и Dummy baseline на общих данных и фолдах. По максимальному CV F1 выбрана SVM с RBF-ядром, C=10, gamma="scale", class_weight="balanced". Средний CV F1 = 0.7667, локальный Test F1 = 0.7234.

SVM превзошёл сравниваемый бустинг по CV (0.7667 против 0.7588) и Test F1 (0.7234 против 0.7143). Это аргумент эффективности SVM для выбранной метрики и проверенных конфигураций. Accuracy и Precision у SVM ниже; на test KNN имеет более высокий F1, поэтому универсальная победа SVM не заявляется. Различия CV невелики относительно межфолдового разброса.

Важности дерева, леса и бустинга сопоставлены с EDA. Для RBF-SVM встроенная feature_importances_ отсутствует. Ошибки основной SVM исследованы по группам и конкретным пассажирам. Порог F1 > 0.70 локально выполнен; результат скрытого теста неизвестен. Эта SVM используется как исходная модель для подбора гиперпараметров в лабораторной № 3.
