| Модель | Accuracy | Precision | Recall | F1 |

По CV заранее выбран **Gradient Boosting**, средний CV F1 = **0.7588**.

У KNN выше F1 на конкретном test, но модель не перевыбирается после просмотра тестовой таблицы.
Порог локально пройден четырьмя алгоритмами; дерево порога не достигло, что отражено в отчёте.

## Данные и условия сравнения

Источник — предоставленный `Titanic-Dataset.xls`, фактически CSV с неправильным расширением.
Файл сохранён без изменения содержимого как [data/titanic.csv](data/titanic.csv).
Загрузка выполняется через `pandas.read_csv`; Excel-библиотеки не нужны.

- 891 пассажир, 12 исходных столбцов, полных дубликатов нет.
- Использованы Age, SibSp, Parch, Fare, Pclass, Sex, Embarked.
- Survived отделён от признаков. PassengerId, Name, Ticket, Cabin исключены.
- Стратифицированное разбиение 80/20, `random_state=42`: train 712, test 179.
- На train: 439 погибших и 273 выживших; на test: 110 и 69 соответственно.
- Для каждого из пяти обязательных алгоритмов проверены три варианта по общей 5-fold StratifiedKFold.
- Числовые пропуски заполнены медианой, категориальные — модой; категории закодированы One-Hot.
- Для SVM и KNN применяется StandardScaler числовых признаков; деревья не масштабируются.
- Все обучаемые преобразования входят в Pipeline и рассчитываются отдельно на обучении каждого фолда.
- Порог классификации не подбирался по test, используется штатный `predict` каждой модели.

В ноутбуке `final_model` — выбранный Pipeline, `y_pred` — его тестовые классы.
Для новых пассажиров:

```python
prediction = final_model.predict(new_passengers[feature_columns])
```

`new_passengers` должна содержать семь указанных исходных столбцов; правильный ответ Survived не нужен.
